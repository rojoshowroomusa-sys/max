### Design specificity verdict

Second pass, after `harden` / `adapt` / `clarify` / `overdrive` / `polish`. The previous snapshot (2026-09-27T13-54-14Z, 20/32, 1 P0 + 4 P1) is the input this was scored against.

The category-interchangeability verdict is materially weaker now. The old critique's central claim was that the structural layer contributed nothing — "the rugby lives in the adjectives, not in the composition" — and that a coffee roaster could run this file with the words swapped. There is now geometry: horizontal pitch lines across the accent band, a touchline that draws itself in the outer margin against the document scroll, jersey numbers 01–04 above the section titles, a slow ember breathing through the brick, print grain over the whole page and residual heat in the footer. None of it is skeuomorphic and none of it needed WebGL or a library. A coffee roaster would have to delete all of it to ship.

The old P0 is closed. The brand no longer disagrees with itself: "Temple" a secas appeared in eight rendered places and is now "Temple XV" in twelve, with the identity string consistent across `<title>`, `og:site_name`, `og:title`, `twitter:title`, nav, the `sr-only` name of the `h1`, the footer `h4` and the footer legal line. One residual visual gap, tracked as a question below: the wordmark lockup itself still renders six letters and no XV, so the hero's emotional beat still does not literally spell the name.

The old P1s are four-for-four closed. `aria-current` was silently wrong for all of `#accesorios` because the observer filtered sections down to those with a nav link; the nav now carries a fourth destination, the observer watches every `main > section` so the unlinked band gets its moment too, and only sections that actually have a link receive `aria-current`. The three `.access` links had zero affordance and now reuse `.product-cta` verbatim rather than growing a variant, so the signal that all six products are purchasable is identical in both grids. The `≤640px` rule that deleted three of five destinations with no replacement is now a real disclosure at `≤900px` with `aria-expanded`, Escape, click-outside and focus return. Failed images, an unset WhatsApp number and a dead `IntersectionObserver` all have defined fallbacks.

What is still weak is not the interface. It is the catalogue: no sizes, no colours, no fit, no stock state, no shipping, no returns. For a brand whose most expensive line is a `$ 168.000` jacket, the likeliest error — ordering the wrong size — is entirely unguarded, and the prefilled WhatsApp text names the product while asks nothing. That is a product decision, not a copy pass, and inventing a sizing policy here would have been the wrong call.

### CSP

`script-src` and `style-src` are hash-pinned and `'unsafe-inline'` is gone from both. One inline `<style>` and one inline `<script>`, zero `style=""` attributes, zero inline event handlers. The two remaining literal occurrences of the string `unsafe-inline` in `_headers` are both inside explanatory comments, not in the directive.

One regression was caught and fixed in this pass: `overdrive` added the forge grain as a `data:image/svg+xml` URI inside a `background-image`, and `img-src` governs CSS `url()` as well as `<img>`. Under the hardened `img-src` the grain would not have loaded. It is now `images/forge-grain.svg`, an ordinary asset covered by the existing `/images/*` immutable rule, so `data:` never had to be reopened.

### Open questions for the brand owner

1. **WhatsApp number.** `meta[name="temple:wa"]` is still `REEMPLAZAR`. The architecture is done and dormant; filling in an E.164 value is the only change needed to activate direct-to-chat, and it is the single highest-value edit left.
2. **Wordmark.** The `h1` lockup renders `T-E-M-P-L-E` with no XV. Everything else says Temple XV. Is the asset intentionally `TEMPLE`, or is the XV missing from the markup?
3. **Currency.** Is `$ 89.000` intentional ARS formatting, or should it carry `ARS`?
4. **Catalogue.** Sizes, colours, fit notes and stock state are absent by choice or by omission?
5. **`También` → `Si no usás WhatsApp`** was a copy judgement made without asking. It is a heading rewrite, reversible in one edit if the original voice was intended.
6. **Lookbook captions were not rewritten.** "caption de cuaderno" was read as a visual treatment rather than a copy rewrite, because "El tackle no es el final. Es el principio de levantarse." was already the best writing on the page.
