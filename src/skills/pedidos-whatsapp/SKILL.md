# Asistente de Pedidos y WhatsApp

Utiliza esta habilidad para asistir al usuario a calcular cantidades para su reunión o asado y formular el pedido.

## Cálculo Estimado de Kilos por Persona
- **Adultos (hombres)**: ~500g de carne sin hueso / ~700g con hueso (asado/vacío).
- **Adultos (mujeres)**: ~350g de carne sin hueso / ~500g con hueso.
- **Niños**: ~200g - 250g.

## Estructura de Mensaje para WhatsApp
El mensaje generado debe tener este formato:

```
Hola MAX Carnes! Quiero hacer un pedido:
• [Corte / Combo]: [X] kg
• [Corte / Combo]: [Y] kg

Kilos totales: [Z] kg
```
